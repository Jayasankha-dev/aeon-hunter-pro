# Aeon Hunter (Neon Ghost Theme Override & Fuzzing Engine)

Aeon Hunter is a specialized browser-level security reconnaissance and automated payload injection utility suite. It features custom cyber-themed styling, a multi-provider neural/AI analysis handler, and an automated fuzzer engine designed for handling structured payload execution and evidence vault management.

---

## 🚀 What This Tool Can Actually Do

Forget the fluff—here is the breakdown of the core functionalities implemented across the codebase:

* **Neon Cyber Theme UI Styling (`theme.css`)**: 
  * Injects a dark-mode, high-contrast neon/matrix-blue (`#00f2ff`) aesthetic overlay directly onto targeted dashboards, panels, and input elements with customized glowing branding animations.
* **Automated Payload Fuzzing Engine (`fuzzer.js`)**: 
  * Manages sequential strike loops to inject custom lists or file-based payloads into active browser tabs via the Chrome Tabs API.
  * Includes safety delays (`1.2s` intervals) to prevent browser lockups and handle basic rate limits.
* **Encrypted Arsenal & Base64 Decoding**: 
  * Dynamically fetches, decodes, and fires pre-configured or encoded payloads on-the-fly from an internal repository.
* **Multi-Provider Neural Link & AI Routing (`aiHandler.js`)**: 
  * Connects with major LLM backends (OpenAI, Gemini, Groq, and Anthropic) using local storage configuration.
  * Enforces strict, automated hacker behavior protocols (clinical tone, uppercase output, terminal syntax tags, and vulnerability classification).
* **Secure Evidence Vault & CSV Export**: 
  * Records execution hits securely using safe DOM manipulation (`textContent` to prevent HTML/script execution inside logs).
  * Automatically formats and exports session results into downloadable CSV reports via secure Blob URLs.
